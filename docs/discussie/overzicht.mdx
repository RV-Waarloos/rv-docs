# Discussie over de RV Waarloos Website

## Doelstelling van deze discussiepagina's

Deze discussiepagina's hebben als doel om de verschillende aspecten van de RV Waarloos Website te bespreken en te evalueren, met name inzake architectuur, gebruikersbeheer en functionaliteiten.

Per onderwerp wordt een aparte discussiepagina aangemaakt. Op deze manier kunnen de verschillende onderwerpen afzonderlijk besproken worden, zonder dat er verwarring ontstaat tussen de verschillende onderwerpen.

Het is eveneens de bedoeling dat de discussiepagina's gebruikt worden om beslissingen te nemen over de verschillende onderwerpen. De beslissingen worden op de discussiepagina's genoteerd, zodat iedereen kan zien wat er besloten is.

Op basis van de beslissingen kunnen de nodige aanpassingen aan de website gedaan worden. De aanpassingen worden eveneens op de discussiepagina's genoteerd, zodat iedereen kan zien wat er aangepast is.

Op deze manier wordt een overzicht gecreëerd van de verschillende onderwerpen, de beslissingen die genomen zijn en de aanpassingen die gedaan zijn. Dit overzicht kan gebruikt worden om de werking van de website te evalueren en te verbeteren.

Op basis van de genomen beslissingen wordt de roadmaps van de website aangepast. De roadmap wordt op de discussiepagina's genoteerd, zodat iedereen kan zien wat er gepland is.
