# Broncode Repositories

Alle broncode van de RV Waarloos omgeving is opgeslagen in Git repositories. Deze repositories bevatten de code voor de verschillende componenten van de omgeving, zoals de webapplicatie, API's en andere services.

GitHub is een populaire platform voor het hosten en beheren van Git repositories. Het biedt functies zoals versiebeheer, samenwerking en issue tracking, waardoor het een ideale keuze is voor het beheren van de broncode van de RV Waarloos omgeving.

Alle repositories zijn ondergebracht in de GitHub organisatie `RV-Waarloos`. U kunt toegang krijgen tot de repositories via de volgende link: https://github.com/RV-Waarloos

Alle repositories zijn private en alleen toegankelijk voor geautoriseerde gebruikers. Als u toegang wilt krijgen tot de repositories, neem dan contact op met de beheerder van de RV Waarloos omgeving.

Geautoriseerde gebruikers kunnen toegang krijgen tot de repositories door een uitnodiging te accepteren die zij via e-mail ontvangen. Na het accepteren van de uitnodiging kunnen zij de repositories klonen, wijzigingen aanbrengen en bijdragen aan de ontwikkeling van de RV Waarloos omgeving.

De eigenaars van de GitHub organisatie `RV-Waarloos` zijn Luc van Keer en Peter Lauwers. Zij zijn verantwoordelijk voor het beheer van de repositories en het toewijzen van toegangsrechten aan geautoriseerde gebruikers.
